Unggah Database SDM

Unggah file Excel dengan 3 sheet: Database SDM AKTIF, TERMINASI, dan Mutasi. Sistem otomatis memproses ketiganya sekaligus dan memisahkan data sensitif sesuai levelnya masing-masing.

🔒 Karyawan aktif: info dasar bisa dilihat staff SDM, data sensitif (HP/Email/Alamat/BPJS) khusus administrator.
🔒 Karyawan terminasi: seluruh data khusus administrator, tidak terlihat oleh staff SDM.
🔒 Mutasi: riwayat jabatan/wilayah bisa dilihat staff SDM, kolom Penyesuaian Gaji khusus administrator.
